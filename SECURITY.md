# Security Policy

## Supported Versions

Only the latest release is currently supported with security updates.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately.

- **Do not** open a public issue for security problems.
- Use GitHub's
  [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability).
- Include steps to reproduce, affected versions, and any relevant details.

We will acknowledge your report within **5 business days** and aim to provide a
resolution or mitigation timeline after triage.
